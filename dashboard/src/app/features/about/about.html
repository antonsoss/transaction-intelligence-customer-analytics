This project uses the Financial — PKDD'99 Financial Dataset (Berka) ↗ to study banking behavior, changes over time, service associations, customer segments, and behavioral outliers. This project includes a limited loan-repayment case study to demonstrate supervised learning concepts from the course. It is intended for education and analysis only, not for fraud detection or automated lending decisions.
