Validation and insights

Model results, data checks, and limitations.

This page uses logistic regression to predict whether a completed loan ended with or without a recorded repayment problem, using only information available when the loan began. It evaluates those predictions on held-out historical loans and also reviews data coverage, model errors, cluster stability, and the limits of the findings.

How to read the measures

Precision
When the model flags a problem, how often is it correct?
Recall
Of the recorded problem loans, how many does the model find?
F1
One measure that balances precision and recall.
PR-AUC
A summary of precision and recall across many cutoffs.
ROC-AUC
How well the model ranks recorded-problem loans above other loans across many cutoffs.
